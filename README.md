# よめる！英語読解

高校入試に向けた、中学3年生の英語読解練習用サイトです。スマートフォンのSafariやChromeで開けます。

## パソコンで起動する

1. このフォルダーでターミナルを開きます。
2. `python3 -m http.server 8000 --bind 0.0.0.0` と入力します（Macには通常Pythonが入っています）。
3. パソコンで `http://localhost:8000` を開きます。

同じWi-Fiにつながったスマートフォンからも使うときは、パソコンのWi-Fiアドレス（Macならターミナルで `ipconfig getifaddr en0`）を調べ、スマートフォンで `http://そのアドレス:8000` を開きます。

### ホーム画面に追加・オフライン利用

サイトをHTTPSで公開すると、iPhoneはSafariの共有メニューから「ホーム画面に追加」、AndroidはChromeのメニューから「インストール」または「ホーム画面に追加」ができます。インストールは任意です。最初にページを開くと基本画面のファイルが保存され、次回からオフラインでも英文練習を使えます。写真の文字読み取りにはインターネット接続が必要です。今の `http://そのアドレス:8000` は同じWi-Fi内で使うための開発用URLで、スマートフォンでホーム画面追加やオフライン機能を使うにはHTTPSの公開先が必要です。

GitHub Pagesで公開する場合は、GitHubにプロジェクトをpushし、リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選びます。このフォルダーにはpushのたびに自動公開するワークフローを用意しています。GitHub FreeではリポジトリとWebサイトが公開状態になります。Webサイトは誰でも見られます。学習データはWebサイトへ送られず、各生徒のブラウザ内に保存されます。

写真の文字読み取りではTesseract.jsを読み込みますが、写真そのものは外部に送らず、ブラウザ内で処理します。自動で問題を作るAIサービスは使いません。

## 保存について

英文、先生の指示、問題、復習記録はブラウザのlocalStorageに保存されます。アカウントやサーバーへの送信はありません。原則として同じブラウザ・同じ端末で開いてください。ブラウザのデータを消すと学習記録も消えます。ホームの「バックアップ」からJSONファイルを保存し、安全な場所に保管してください。

## いまできること

- 英文を読み、大切な内容・細かい内容・単語・推理の問題に答える
- 問題を手動で追加する
- 間違えた理由を選んで復習する。正解した問題は復習リストから消え、以前の回答は履歴に残ります
- 途中でやめても、次回は最後の問題から続ける
- 練習する力を選び、その力の問題だけにしぼる
- ポイント、レベル、バッジと1日3問のチャレンジで、続けた成果を見えるようにする
- まちがえた問題から単語ノートを作り、自分の意味や例文を書いて、意味をかくしたカードで復習する
- 単語ノートの復習は、思い出せたことばほど次の復習までの日数が長くなります。まだ難しいことばは、あとでもう一度出ます
- 英文を追加するとき、ヒント・解説を各問題のあとに見るか最後にまとめて見るか選べる。日本語訳は自分で入力し、問題のあとか練習の最後に表示できる
- ホームの「バックアップ」から学習データをJSONファイルに保存・復元できる。復元は現在のデータに追加し、上書きしない
- 英文をブラウザの音声読み上げで聞く
- 「やさしい先生」「元気な友だち」など4つの話し方を選び、見本を聞き比べる（声の高さと速さを調整。聞こえ方は端末によって異なる）
- 必要なら、端末に入っている別の英語の声も選べる
- 自分の音読を録音し、停止後に聞き直す（録音は英文ごとに端末へ保存。新しい録音は確認後に上書き可能、2分で自動停止）
- 英文の貼り付け、または写真から英語を読み取って編集する

読み上げの音声や写真読取の精度は端末・ブラウザにより異なります。手本の問題は動作確認用のサンプルで、自分の英文と問題を追加できます。

音読録音はマイクを使うため、録音ボタンを押したときにブラウザの許可が必要です。HTTPSのサイト、またはパソコン自身の `localhost` で使えます。スマートフォンで録音するには、HTTPSで公開したサイトを使ってください。録音ファイルはIndexedDBに保存され、JSONバックアップには含まれません。必要ない録音は音読画面の「録音を削除」から消せます。
